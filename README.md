# Trade Platform Website
A complete trading platform built with HTML, CSS, and JavaScript — works fully in browser, no extra setup needed. Includes user system, live charts, deposits, withdrawals, and admin panel to manage all payments.

---

## ✨ Main Features
- ✅ User Registration & Login System
- ✅ 2 Account Types:
  - **Demo Account** → Practice with virtual money (10,000 Ksh free)
  - **Real Account** → Live trading, real funds, withdraw enabled
- ✅ Live Candlestick Charts (real-time price movement)
- ✅ Trade Assets: EUR/USD, GBP/USD, USD/JPY, AUD/USD
- ✅ Trade Durations: 5 Sec, 10 Sec, 30 Sec, 1 Min
- ✅ Deposit System: select amount → send via M-Pesa → admin approves → balance updates
- ✅ Withdraw System: **Processed within 1 minute** — sent directly to user's M-Pesa
- ✅ Admin Panel: view all pending payments, approve or reject, update balances automatically
- ✅ Trade History & Statistics (Win rate, total trades, profit, best trade)
- ✅ Professional Win/Lose Popup Notifications
- ✅ Fully responsive — works on all phones & computers

## 🚀 How It Works

### For Users:
1. **Register** → create username & password
2. **Login** → enter your details
3. **Choose Account**: Demo (practice) or Real (live funds)
4. **Deposit**: select amount → send to `0758903057` → admin approves → balance updates
5. **Trade**: choose asset & time → enter amount → click HIGHER / LOWER → see result
6. **Withdraw**: only Real Account | Min 100 Ksh | Max 50,000 Ksh | processed in 1 minute

### For Admin:
1. Login with `admin` / `admin123`
2. See all pending payments
3. **APPROVE** → user balance increases | **REJECT** → request cancelled
4. All actions saved automatically
